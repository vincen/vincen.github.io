# Herfindahl-Hirschman Index

赫芬达尔-赫希曼指数（Herfindahl-Hirschman Index，简称 **HHI**）是衡量市场集中度和产业竞争状况最常用的经济学指标，通过计算行业内所有企业市场份额的平方和得来。

**计算公式**

$$HHI = \sum_{i=1}^{n} S_i^2 = S_1^2 + S_2^2 + \dots + S_n^2$$

- **$S_i$**：第 $i$ 家企业的市场百分比份额（如百分之二十取值为 $20$）。
- **$n$**：行业内的企业总数。
- **取值范围**：接近 $0$（极度分散的完全竞争）至 $10,000$（单一企业 $100\%$ 占领的完全垄断）。

**市场集中度划分标准（参考反垄断监管实践）**

| **HHI 数值区间**              | **市场结构分类** | **竞争状况与监管影响**                                       |
| ----------------------------- | ---------------- | ------------------------------------------------------------ |
| **$HHI < 1,500$**             | 低度集中         | 市场属于完全竞争或垄断竞争，竞争充分                         |
| **$1,500 \le HHI \le 2,500$** | 中度集中         | 呈现一定程度寡头垄断，并购可能引发监管关注                   |
| **$HHI > 2,500$**             | 高度集中         | 属于强寡头或完全垄断，若并购导致 $HHI$ 显著上升（如增量超 $200$）易触发反垄断调查 |

**计算示例**

假设某市场仅有 4 家企业，市场份额分别为 40%、30%、20%、10%：

$$HHI = 40^2 + 30^2 + 20^2 + 10^2 = 1,600 + 900 + 400 + 100 = 3,000$$

结果大于 $2,500$，表明该市场属于**高度集中的寡头市场**。

**核心特点与优势**

- **强调大企业的影响力**：通过对市场份额进行**平方运算**，大企业的权重被放大。例如“两家各占 50%”与“五家各占 20%”的市场，$CR_4$（前四家集中率）均显示为 100%，但后者的 $HHI$ 仅为 $2,000$（中度集中），而前者高达 $5,000$（极高集中），$HHI$ 能更真实地反映头部垄断程度。
- **兼顾全部市场参与者**：不同于只看前几名份额的行业集中度指标（如 $CR_4$、$CR_8$），$HHI$ 涵盖了市场内所有企的数据，计算更加全面。
- **反垄断审查的核心工具**：各国的反垄断机构（如中国国家市场监管总局、美国司法部及 FTC）在审查企业兼并与收购（M&A）时，均将交易前后的 $HHI$ 及其变化量（$\Delta HHI$）作为判定是否构成排除或限制竞争的核心依据。
