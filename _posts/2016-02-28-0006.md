# 挣值分析法

## 场景描述

1. 砌一堵长度为100米的围墙，假设预算单价是100元每米，共100\*100=10000元，计划项目工时10天（每天砌墙10米）来完成这个项目。
2. 在第四天工作结束的时候对该项目进行绩效评估。
3. 第四天工作结束的时候，我们计划是要完成40米的任务，这个40米的工作量的价值是40米\*100元/米 = 4000元，这个4000元就是我们的计划价值PV（计划做多少事）。
4. 检查发现第四天工作结束实际才完成了30米砌墙任务，对应的价值是30米\*100元/米=3000元，这个3000元就是我们的挣值EV（实际做了多少事），也就是在第四天结束完成了3000元的工作量。
5. 到第四天结束这个时间点我们实际却花了5000元，这个5000元就是我们的实际成本AC（实际花了多少钱）。
6. 总的预算10000元就是我们的完工预算BAC；
7. 总结：一共计划10000元10天完成这个项目，在第四天结束的时候去检查项目绩效，发现到这个时间点为止本来应该完成4000元的项目工作量（PV），结果只完成了3000元的工作（EV），却花了5000元的成本（AC）。
8. 评估项目绩效时，本来计划完成40米4000元的工作量（PV），结果只砌了30米只完成了3000元的工作量（EV），那么：
9. 进度偏差SV=EV-PV=3000-4000=-1000元，意思是相比计划我们的进度落后1000元的工作量；（负值表示进度落后，正值表示进度超前）
10. 进度绩效指数SPI=EV/PV=3000/4000=0.75，说明当前只完成了计划任务量的75%的工作；
11. 成本绩效的检查结果是：只完成3000元的工作量（EV）实际却花了5000元（AC）。这个时候：
12. 成本偏差CV=EV-AC=3000-5000=-2000元，说明现在成本超支了2000元（负值表示超支，正值表示节约）；
13. 成本绩效指数CPI=EV/AC=3000/5000=0.6，意思是前面4天我们实际花了5000元，但是只做了3000元的工作，相当于前面4天我们每花1元钱，只做了0.6元的事；
14. 对于CPI的计算方法和意义一定要非常熟悉，CPI的意义是每花1元钱做了多少钱的事（花钱的效率），CPI为0.6的意思就是每花1元钱只做了0.6元的事，所以CPI的计算方法是做了的事（EV）除了花了的钱（AC）。

## 基本参数

| 参数                                  | 概念                                                         | 计算公式                | 示例                       |
| ------------------------------------- | ------------------------------------------------------------ | ----------------------- | -------------------------- |
| Planned Value（PV，计划价值）         | 截止到某时间点，计划要求完成的工作量所需的预算工时（或费用） | 计划工作量  * 计划单价  | 40米 * 100元/米 = 4000元   |
| Actual Cost（AC，实际成本）           | 截止到某时间点，实际完成的工作量所消耗的工时（或费用）       | 已完成工作量 * 实际单价 | 5000元                     |
| Earned Value（EV，挣值）              | 截止到某时间点，实际完成工作量及按预算定额计算出来的工时（或费用） | 已完成工作量 * 计划单价 | 30米 * 100元/米 = 3000元   |
| Budget At Completion（BAC，完工预算） | 对完成该项目的计划预算（或工时）                             | 计划工作量 * 计划单价   | 100米 * 100元/米 = 10000元 |

## 绩效指标

| 参数                                            | 概念                                                         | 计算公式                    | 示例                  |
| ----------------------------------------------- | ------------------------------------------------------------ | --------------------------- | --------------------- |
| Schedule Variance（SV，进度偏差）               | 当 SV 为正值时，表示进度提前； 当 SV 等于零时，表示实际与计划相符。 当 SV 为负值时，表示进度延误。 | SV = EV - PV = BCWP - BCWS  | 3000 - 4000 = -1000元 |
| Cost Variance（CV，成本偏差）                   | 当 CV 为正值时，表示实际消耗的人工（或费用）低于预算值，即有结余或效率高； 当 CV 等于零时，表示实际消耗的人工（或费用）等于预算值； 当 CV 为负值时，表示实际消耗的人工（或费用）超出预算值或超支。 | CV = EV - AC = BCWP - ACWP  | 3000 - 5000 = -2000元 |
| Cost Performance Index（CPI，成本绩效指标）     | 是反映项目在成本执行和控制方面的一个主要衡量指标。当 CPI>1 时，表示低于预算；当 CPI=1 时，表示实际费用与预算费用吻合； 当 CPI<1 时，表示超出预算。 | CPI = EV / AC = BCWP / ACWP | 3000 / 5000 = 0.6     |
| Schedule Performance Index（SPI，进度绩效指标） | 是反映项目在进度执行和控制方面的一个主要衡量指标。当 SPI>1 时，表示进度超前；当 SPI=1 时，表示实际进度与计划进度相同；当 SPI<1 时，表示进度延误。 | SPI = EV / PV = BCWP / BCWS | 3000 / 4000 = 0.75    |

## 预测指标

1. Estimate To Completion（完工尚需估算）

   - **含义**：指从**当前时间节点**直到项目最终完工，估计**还需要追加支出**的成本金额。

   - **计算公式**（根据对未来绩效的假设不同分三种常见情况）：
     - **非典型偏差（未来按计划预算执行）**：假设之前的偏差属于偶然事件，剩余工作将按原预算标准执行。$$\text{ETC} = \text{BAC} - \text{EV}$$
     - **典型偏差（未来按当前 CPI 效率执行）**：假设过去的成本绩效代表未来趋势，剩余工作将维持当前的成本效率。$$\text{ETC} = \frac{\text{BAC} - \text{EV}}{\text{CPI}}$$
     - **重新自下而上估算（Bottom-up ETC）**：原计划已严重失真，对剩余未完成的工作进行重新逐项估算。$$\text{ETC} = \text{重新逐项估算的所有剩余工作成本总和}$$

2. EAC (完工估算)

   - **含义**：指截至当前预测，预计项目**最终全部完工时**所需要的**总成本**。

   - **通用计算公式**：$$\text{EAC} = \text{AC} + \text{ETC}$$

   - **衍生公式（根据不同情况代入 ETC 展开）**：
     - **非典型偏差（未来按原计划预算执行）**：$$\text{EAC} = \text{AC} + \text{BAC} - \text{EV}$$
     - **典型偏差（未来按当前 CPI 效率执行）**：$$\text{EAC} = \frac{\text{BAC}}{\text{CPI}}$$
     - **受成本与进度双重重影响（考虑 CPI 和 SPI 的复合作用）**：$$\text{EAC} = \text{AC} + \frac{\text{BAC} - \text{EV}}{\text{CPI} \times \text{SPI}}$$

3. VAC (Variance at Completion / 完工偏差)
   - $$\text{VAC} = \text{BAC} - \text{EAC}$$
   - 预测项目最终完工时的总预算盈亏情况。$\text{VAC} > 0$ 表示最终有结余，$\text{VAC} < 0$ 表示最终会超支。

4. TCPI (To-Complete Performance Index / 完工尚需绩效指数)**： 为了在特定预算目标（BAC 或 EAC）内按时完成剩余项目，未来**剩余工作必须达到的成本效率指数。

   - **基于原批准预算 BAC 衡量**（用于评估能否按原计划预算守住底线）：$$\text{TCPI}_{\text{BAC}} = \frac{\text{BAC} - \text{EV}}{\text{BAC} - \text{AC}}$$


   - **基于调整后的新完工估算 EAC 衡量**（用于评估能否在修正后的预算内完成）：$$\text{TCPI}_{\text{EAC}} = \frac{\text{BAC} - \text{EV}}{\text{EAC} - \text{AC}}$$


   - $\text{TCPI} > 1.0$ 说明未来的工作必须付出高于平均水平的效率才能完成预算控制目标（难度大）；$\text{TCPI} \le 1.0$ 说明维持现状或稍有放缓即可完成目标。
